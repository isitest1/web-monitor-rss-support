プライバシーポリシー Privacy Policy

開発者は利用者のデータを一切受け取りません The developer never receives any of your data

最終更新日：2026年9月11日 Last updated: September 11, 2026

Web Monitor RSSは自己ホスト型のオープンソースソフトウェアです。拡張機能が収集するデータは、利用者ご自身が設定したバックエンド（ご自身のCloudflareアカウント）にのみ送信され、開発者（Margherita Works）のサーバーには一切送信されません。 Web Monitor RSS is self-hosted, open-source software. Data the extension collects is sent only to the backend you configure yourself (your own Cloudflare account) — never to any server operated by the developer (Margherita Works).

1. アーキテクチャについて（重要） 1. About This Architecture (Important)

この拡張機能には中央サーバーがありません。利用者はオープンソースのバックエンドをご自身のCloudflareアカウントにデプロイし、拡張機能のオプション画面でそのURLとトークンを設定します。拡張機能が送信するすべてのデータは、この利用者自身のバックエンドにのみ届きます。開発者は利用者がどのURLを設定したかも、そこに何が送信されたかも一切知ることができません。This extension has no central server. You deploy the open-source backend to your own Cloudflare account and configure its URL and a token in the extension's options page. Everything the extension sends goes only to that backend of yours. The developer has no visibility into what URL you configured or what was sent to it.

2. 収集する情報 2. Information Collected

拡張機能が扱うのは以下のみです：The extension handles only:

  • 利用者がVisual Selectorでクリックして選択した、ページ内の特定要素のテキスト・HTML（明示的に有効化した場合のみ）・属性値・リンクURL・画像URL
  • The text, HTML (only if you explicitly enable it), attribute value, link URL, or image URL of the specific page element(s) you click to select with the Visual Selector
  • 拡張機能の設定（バックエンドのURLとAPIトークン）— 拡張機能のローカルストレージにのみ保存
  • The extension's own settings (backend URL and API token) — stored only in the extension's local storage

以下は一切収集・保存しません：The extension never collects or stores:

  • ページ全体のHTML
  • Full page HTML
  • Cookie、ログイン情報、認証セッション
  • Cookies, login credentials, or authentication sessions
  • 閲覧履歴、利用状況の分析データ
  • Browsing history or usage analytics

3. データの送信先 3. Where Data Is Sent

選択した要素の値は、利用者がオプション画面で設定したバックエンドURLへ、設定したトークンで認証された上で送信されます。それ以外の宛先へ送信されることはありません。アナリティクスSDK・広告SDK・トラッキングSDKは組み込まれていません。The value of a selected element is sent to the backend URL you configured in the options page, authenticated with the token you configured there. It is never sent anywhere else. The extension contains no analytics, advertising, or tracking SDKs.

4. ページへのアクセス権限について 4. About Website Access Permissions

この拡張機能は、任意のWebサイトを監視対象として選択できるようにするため、すべてのサイトへのアクセス権限を要求します。この権限は以下の目的にのみ使用されます：This extension requests access to all websites so that you can choose to monitor any page you like. This access is used only to:

  • 利用者が拡張機能を開いて選択操作を行ったページのDOMを読み取り、選択候補をハイライト表示するため
  • Read the DOM of a page you've opened the extension on, so it can highlight candidate elements as you hover and click
  • 「ローカル実行モード」に設定したMonitorについて、Chromeが起動している間、バックグラウンドタブで該当ページを開いて確認するため（この場合もページ全体ではなく設定済みの範囲のみを抽出します）
  • For Monitors set to "local" execution mode, open the page in a background tab (while Chrome is running) to re-check it — even then, only the configured selection is extracted, never the whole page

拡張機能が能動的に全サイトを巡回・監視することはありません。利用者が明示的に選択・設定したページのみが対象です。The extension never proactively crawls or monitors sites on its own — only pages you have explicitly selected or configured are ever touched.

5. 対象外とする用途 5. Out of Scope by Design

本ソフトウェアは、CAPTCHA回避、アクセス制御の回避、ペイウォール回避、その他サイト側の制限を回避する目的の機能を実装していません。またログインを必要とするページの監視は想定していません。This software implements no CAPTCHA bypass, access-control bypass, paywall bypass, or other functionality designed to evade a site's own restrictions. It is not designed to monitor pages that require a login.

6. オープンソースであること 6. Open Source

拡張機能とバックエンドのソースコードはすべてGitHubで公開されています。このポリシーの記述内容は、実際のコードで検証いただけます。The full source code for both the extension and the backend is public on GitHub. Everything stated in this policy can be verified against the actual code.

7. 子供のプライバシー 7. Children's Privacy

本拡張機能は13歳未満の子供を対象としておらず、意図的に情報を収集することはありません。This extension is not directed at children under 13 and does not knowingly collect information from them.
